STREET CHASERS — E-COMMERCE WEBSITE STARTER
============================================

CONTENTS
- index.html  Website page structure
- style.css   Responsive visual design
- script.js   Product manager, search, and WhatsApp quote/order links
- images/     Put any extra image files here if you want (product images are uploaded through the website manager)

HOW TO OPEN
1. Extract Street_Chasers_Website.zip to a folder.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome or Edge.
   Or open the folder in Visual Studio Code and use Live Server if you have that extension.

HOW TO ADD PRODUCTS
1. Open the website.
2. Scroll to MANAGE PRODUCTS.
3. Enter the product name, price in MWK, category, sizes, description, and photo.
4. Click "Add product".
5. Use Edit product or Delete on each product card to manage products.
6. Use "Export product list (JSON)" to keep a backup. Import it on the same or another browser if needed.

IMPORTANT LIMITATIONS
- This is a front-end starter website. It does not take card/mobile-money payments itself.
- Products are saved in the current browser's local storage. They are not automatically shared with customers, synced to other devices, or backed by a server.
- The product manager is not password protected. Do not publish this exact version as a public admin system: anyone who opens the site can potentially manage products in their own browser. For a real public store, we should add a protected admin login and a database/backend, then host it online.
- Opening index.html locally means only you can see that local copy. To make the store public, publish the files to a hosting provider.
- The Google Fonts import requires an internet connection; the site still works without it using fallback fonts.
